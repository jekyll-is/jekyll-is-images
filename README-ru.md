# jekyll-is-images

Jekyll-плагин для работы с картинками и галереями.

## Использование

### Markdown-расширение

#### Изображения

Используется стандартный синтаксис `![Alt text](source){: attributes }`. Однако набор атрибутов не просто передается в HTML,
а интерпретируется для преобразований. При этом привычные `#id`, `.class_name`, `style="border:none;"` работают так же, как
и в базовом Kramdown.

Расширенные атрибуты:

`format="webp|avif|png|jpeg|tiff|..."`

: Целевой формат. Как правило, не требует указания, вместо этого настраивается в конфигурации для всего сайта. См. ниже.

`href="‹url›|none|view"`

: Ссылка. Т.е. формируется конструкция вида `<a href="..."><img ...></a>`. При этом, если параметр не указан, по умолчанию
  трактуется как `view` — то есть локальная ссылка на бо́льшую версию изображения.

`title="‹string›"`

: Формирует атрибут `title` тега `<a>` (или `<span>`, если `href="none"`). По умолчанию берется текст из `alt`, т.е. то, что
  пишется в квадратных скобках.

`width="‹int›"`

: Ширина картинки, определяет как ширину тега `<img>`, так и (совместно с параметрами `height`, `fit` и `scale`) размер
  преобразованного изображения.

`height="‹int›"`

: Высота картинки.

`fit="contain|cover|fill|scale-down|none"`

: Режим заполнения. Соответствует значениям CSS-свойства `object-fit`, влияет на ресайз картинки. По умолчанию — `contain`.

`scale="‹float›"`

: Коэффициент, на который умножаются `width` и `height` для ресайза. Не оказывает влияние на размеры тега `<img>`. Может быть,
  например, использовано для увеличения картики по `:hover` (передается в CSS-переменную `--is-images-scale`).

`crop="‹int›x‹int›+‹int›+‹int›"`

: Позволяет выбрать область исходной картинки, которая будет взята. Формат: «ШИРИНАxВЫСОТА+СДВИГ_ПО_X+СДВИГ_ПО_Y».

`salt="‹string›"`

: Соль хэша. Позволяет перегенерировать результирующую картинку без изменения значащих параметров.

`lazy`

: Флаг (без значения). Добавляет `loading="lazy"` тегу `<img>`.

#### Иллюстрации

Если картинка находится на строке, отделенной сверху и снизу пустыми строками, в стандартном Kramdown формируется конструкция вида
`<p><img ...></p>`. Плагин заменяет ее конструкцией вида `<figure><img ...></figure>` и дополнительно интерпретирует следующие
атрибуты и флаги:

`caption="‹string›"` или флаг `caption`

: Добавляет тег `<figcaption>`, в форме флага содержимое этого тега берется из `alt`.

`caption-position="top|bottom"`

: Определяет размещение тега `<figcaption>` — сверху или снизу от картинки.

`right` или `left`

: Задает «умное» плавающее положение. В целом соответствует CSS `float:right;` и `float:left;`, но обвязано некоторыми дополнениями —
  рекомендуется использовать именно эти флаги, а не простое указание свойства в `style="..."`.

`shape`

: Формирует обтекание по картинке. Будет работать на форматах с прозрачностью: PNG, WebP и SVG. Работает только для плавающих иллюстраций.

`up="‹int›"` и `shift=‹int›`

: Позволяет сдвинуть картинку относительно нормального положения. `up` сдвигает вверх, а `shift` — вправо или влево, в зависимости
  от положения — всегда наружу, как бы на поля. Работает только для плавающих иллюстраций.

Важный момент: атрибуты и флаги могут быть указаны как в IAL блока, так и в IAL инлайнового элемента, т.е. картинки.

    {: ‹атрибуты блока› }
    ![Alt text](source){: ‹атрибуты изображения› }

Плагин автоматически перенесет атрибуты изображения, относящиеся к блоку в атрибуты блока. Более того, _все_ классы и все флаги, кроме `lazy`,
также будут перенесены в `<figure>`. Значения `style` будут применены раздельно. Это следует иметь в виду при разработке своих CSS, работающих
с плагином. Такая логика введена ради того, чтобы описывать простые иллюстрации одной строкой (т.е. без отдельного прописывания атрибутов блока).
